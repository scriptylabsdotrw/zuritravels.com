# Partner logos

Lodge and camp partners. Used in the home page partners marquee.

## Naming convention

`{kebab-case-brand}.svg` — for example:

```
singita.svg
wilderness.svg
andbeyond.svg
one-and-only.svg
bisate.svg
time-and-tide.svg
```

## Specs

- **Format:** SVG preferred. PNG (transparent, 2×) acceptable.
- **Aspect:** Horizontal lockup. Roughly 4:1 to 6:1.
- **Color:** Dark (#111) version. We tint to neutral-500 in CSS — don't worry about state colors.
- **Padding:** ~10% transparent padding around the mark in the SVG viewBox.
