# Press logos

Publications. Used in the "As featured in" strip on the home page.

## Naming convention

`{kebab-case-brand}.svg` — for example:

```
conde-nast.svg
travel-leisure.svg
robb-report.svg
financial-times.svg
afar.svg
monocle.svg
```

## Specs

- **Format:** SVG preferred.
- **Color:** Single-color dark version (#111). We tint via CSS.
- **Aspect:** Horizontal. Typically 4:1 — 6:1.
- **Background:** Transparent.
